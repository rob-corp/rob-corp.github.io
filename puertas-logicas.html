Teoremas del álgebra booleana

Leyes y propiedades fundamentales empleadas para la simplificación, análisis y optimización de circuitos lógicos combinacionales.

1. Leyes de Identidad Básica
A · 1 = A A + 0 = A

Un valor combinado con la identidad neutra no altera su estado lógico original.

2. Elemento Nulo / Dominancia Absorción Nula
A · 0 = 0 A + 1 = 1

El elemento dominante fuerza el resultado independientemente del valor de A.

3. Idempotencia Redundancia
A · A = A A + A = A

Operar una variable consigo misma múltiples veces resulta en la misma variable.

4. Doble Negación / Involución Inversión
A = A

Invertir dos veces una variable retorna exactamente su estado lógico original.

5. Complemento Anulación
A · A = 0 A + A = 1

Una variable y su inverso garantizan un estado nulo en AND o dominante en OR.

6. Ley Conmutativa Orden
A · B = B · A A + B = B + A

El orden de los operandos no altera el resultado de la función lógica.

7. Ley Asociativa Agrupación
(A · B) · C = A · (B · C) (A + B) + C = A + (B + C)

Agrupar variables de la misma operación no afecta la salida final.

8. Ley Distributiva Factorización
A · (B + C) = A·B + A·C A + (B · C) = (A + B)·(A + C)

Permite la expansión o factorización entre sumas y productos booleanos.

9. Leyes de De Morgan Crucial
A · B = A + B A + B = A · B

La negación de un producto equivale a la suma de sus negaciones y viceversa.

10. Ley de Absorción Simplificación
A · (A + B) = A A + (A · B) = A

Elimina términos redundantes cuando una variable está presente dentro y fuera.

11. Absorción Secundaria Reducción
A · (A + B) = A · B A + (A · B) = A + B

Elimina la variable negada del término secundario simplificando la expresión.

12. Teorema del Consenso Eliminación
A·B + A·C + B·C = A·B + A·C

El término redundante formado por las variables libres (B·C) puede eliminarse.
